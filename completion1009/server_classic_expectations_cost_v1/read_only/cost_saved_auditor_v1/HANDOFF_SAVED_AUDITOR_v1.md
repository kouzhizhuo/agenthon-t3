# Saved-only Stage 1 cost auditor draft

`audit_cost_saved_v1.py` is an independent saved-artifact auditor in a new directory. It performs no participant imports, native compilation, simulation, Docker, network or subprocess execution. Its full acceptance inputs must be an actual complete cost ZIP and the complete external successful delivery v2 ZIP, source/readback and anonymous registry manifest/config/compressed layers. No new cost artifact currently exists, so `all_passed=false`, `ready_for_linux=false` and `official_submission_eligible=false` remain the recorded state.

The auditor copies the exact reviewed cost parser plus the 14 files of the frozen delivery auditor/freeze receipt as references, keeping the existing frozen sources unchanged. `REFERENCE_PINS_v1.json` binds 15 ordinary reference files. It replays all eight frozen parent audit stages in memory before trusting a base, including full ZIP/member CRC, source/C/object/ELF controls, diagnostic/full71 ordinary evidence, resource lifecycle and anonymous layers/config/diffIDs. The failed delivery v1 data is used only in decoder compatibility preflight and is never treated as passing delivery authority.

For the new cost artifact, it requires explicit independent run ID, attempt, head, active workflow and sourcepins, plus explicit actual remote source/evidence/reference/gate paths. It checks the entire carried source tree against the reviewed source freeze and independent same-head readback, then exact `RUN_BINDING.json`. All copied host/source/graph/parser bytes and the separate source-review bindings are checked. The derived overlay ID is separate from the genuine successful base ID. Only one exact immutable FROM and one COPY of the frozen two-file overlay may add one RootFS layer; the public Config and all native/source/C/object/ELF/licence files must remain unchanged before/after.

The 24 diagnostic workers are independently audited from original raw create/start/inspect/remove streams, exact requests, staged typed original scenario/sub/source SHA maps, image metadata and fixed resource contract. Every official gate and full actual output is rechecked. The full raw stdout/stderr is reparsed into complete state files outside the saved artifact; observation, cost clocks/profile/callers, source contract, restoration flags, state metadata, compressed byte counts and full graph hashes must equal the saved receipts. All 40 complete graphs are decoded with the frozen GraphAudit, including MT624, Gaussian state, aliases, clock/queue/ledger identities. All 80 trace/ledger Parquet copies are fully decoded and matched to exact official references and successful v2 ordinary bytes. State/cost and both arms must also match successful base STATE bytes and each other.

Six never-started owned source-copy containers require exact unspecialized create argv, original three roots and separate 16 MiB logs/64 MiB source-file limit, retained raw created identity and settled/removed/absent cleanup. The 27 host processes must comprise exactly 24 fixed diagnostic labels and three fixed audit/pull/build labels, with exact routes, positive PIDs, reaping, caps and complete stream pins. Actual 24 daemon intervals must be positive and strictly serial. The reviewed driver does not retain raw host process start/finish timestamps; host process seriality is source-bound and no timestamps are fabricated. Host image metadata has complete raw streams/IMAGE bytes but no separate per-command returncode JSON; that limitation is explicit.

`archive_wrapper_draft_v1.py` proposes a separately reviewed future workflow step that copies only the actual existing evidence and writes genuine run binding plus a complete byte manifest. It never launches the driver or synthesizes missing market results. The previously reviewed host driver is unchanged. No wrapper or workflow is ready for dispatch until independent review, actual base binding, final source freeze and same-head readback complete.

The source self-check currently has 26 inert ZIP/path/typed-schema/import negatives and positives, plus complete decoding of one real saved 3.7 MiB graph and both real saved Parquets. All source checks pass. These checks do not accept a new cost artifact or prove a performance score. Independent source review remains required before a freeze; the final Linux artifact must separately pass all saved evidence stages.
